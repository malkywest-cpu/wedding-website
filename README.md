# West-Elliott Wedding Website

A beautiful, responsive wedding website built with React, Tailwind CSS, and modern web technologies.

## 🎉 Features

✨ **Beautiful Design**
- Elegant serif typography with custom color scheme
- Smooth animations and transitions
- Fully responsive layout (mobile, tablet, desktop)
- Professional gradient overlays and styling

📋 **Core Sections**
- **Hero Section**: Eye-catching introduction with wedding date and location
- **Venue Details**: Location, schedule, parking information with map
- **Wedding Party**: Showcase of the wedding party with photos and roles
- **Accommodation**: Hotel recommendations and booking information
- **FAQs**: Common questions and answers
- **RSVP Form**: Interactive guest response form with dietary requirements
