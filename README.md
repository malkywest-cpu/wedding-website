# West Wedding

Welcome to the official repository for the West & Elliott wedding website.

This project is the source code for a responsive and functional wedding website.

## Key Features

- **RSVP Form**: Collect and manage guest responses.
- **Venue Details**: Location, schedule, and directions.
- **Meet the Team**: Featuring the wonderful individuals supporting the bride and groom.
- **Accommodation Options**: Suggestions for nearby hotels.
- **FAQs**: Answering common questions for attendees.

## Technologies Used

- React
- TailwindCSS
- Babel (for JSX transpilation)

## Deployment

- Easily deploy this website using platforms like Netlify, Vercel, or GitHub Pages.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/malkywest-cpu/wedding-website.git
   ``` 

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm start
   ```

4. Build the website for production:
   ```bash
   npm run build
   ```

5. Deploy the `build` directory to your preferred hosting platform.
